# Lab-04 - shop-rest (Jakarta REST 4.0 / Jersey 4)

## Build and run
```
mvn -q compile                 # first run downloads all dependencies
mvn -q compile exec:java       # starts the server, Ctrl+C to stop
mvn test                       # runs the JerseyTest classes
```
